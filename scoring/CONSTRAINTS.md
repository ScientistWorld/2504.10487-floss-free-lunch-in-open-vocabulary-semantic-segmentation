# Scientist Constraints

## Model and Features

Use the provided dense visual embeddings and 80-template text embedding pool for `synthetic_ovss`. The benchmark tests text-side adaptation on fixed OVSS-style features. Recomputing features with a stronger image model, adding learned segmentation heads, or replacing the fixed embeddings with a supervised segmenter changes the problem.

## Data

Use only `data/downloads/floss_synthetic.npz` generated by `scripts/download.sh`. The unlabeled training features may be used for adaptation. Validation labels may be used only by `eval/` for final scoring, not for selecting templates, tuning hyperparameters, or making per-class decisions.

## Procedure

Keep the class vocabulary, 80-template pool, train/validation split, and mIoU evaluator fixed. Any method output must be saved as `outputs/<method>/predictions.npy` so `scripts/evaluate.sh` can score it without importing solution code. Methods that claim class-expert selection should also save `outputs/<method>/experts.npy` with shape `[num_classes, num_experts_per_class]` for the diagnostic expert-quality score.

## Compliance Checklist

- [ ] Uses the provided fixed dense features and 80-template text embedding pool
- [ ] Does not use validation labels during adaptation
- [ ] Does not add external labeled segmentation data
- [ ] Writes predictions in the expected output format
- [ ] Writes selected expert indices when claiming expert-selection behavior
- [ ] Uses `scripts/evaluate.sh` unchanged for scoring
